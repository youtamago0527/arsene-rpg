ゲーム開始
GUIDE / FIRST INFILTRATION

遊び方ガイド

初回開始から拠点、戦闘、帰還、セーブまで。最初の潜入で迷わないための手引きです。

1. NEW GAMEを選ぶ

オープニングはSKIPできます。主人公を6人から選び、最大12文字の名前、初期JOB、初期武器を決定すると拠点へ入ります。CONTINUEは同じブラウザに保存済みのデータがあるときに使います。

2. 拠点で準備する

拠点「麺処 おくのほそ道」では、ダンジョン選択、料理、装備、JOB、所持品、工房、図鑑、設定を利用します。最初は表示されない項目も、ボス撃破などの条件を満たすと解放されます。

3. 戦闘コマンドを選ぶ

コマンド役割
たたかう装備中の武器で通常攻撃します。武器学EXPも得られます。
武器技・JOBMPなどを消費して、攻撃・回復・強化を行います。
防御そのラウンドに受ける最終ダメージを50%軽減します。
アイテム回復薬など所持品を使います。
AUTOOFF、1.5倍、2倍を切り替えて自動行動します。

複数の敵がいるときは敵本体をタップして対象を選択できます。状態効果は表示欄をタップすると説明を確認できます。

4. 帰還して育てる

勝利するとEXP、JOB EXP、武器学EXP、GOLD、素材、装備を獲得します。工房で装備を製作・強化・分解し、JOBや装備を見直して次の潜入へ向かいます。通常潜入用の料理効果は帰還や敗北で消えますが、育成や所持品、解放状態は保存されます。

5. セーブを守る

ゲームは進行に応じてブラウザ内へ保存します。ブラウザデータの削除やプライベートブラウズでは消える可能性があります。設定のデータ項目からセーブコードを書き出し、安全な場所へ控えてください。別端末ではセーブコードを読み込んで引き継げます。
