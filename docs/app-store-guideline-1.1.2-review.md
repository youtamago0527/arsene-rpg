# App Store Guideline 1.1.2 再審査監査

監査対象: `feature/ios-capacitor`（監査開始時 `15951e5`）

## 結論

- iOSプロジェクト内に Kids Category、Made for Kids、13歳未満向けを指定する設定は見つからなかった。
- 年齢レーティングそのものはリポジトリではなく App Store Connect の年齢レーティング質問票で設定する。
- 戦闘対象の主要人型キャラクターに、子供・未成年であることを明示する設定は見つからなかった。
- 最大の誤認リスクだった、OPでルナが連れ去られる2カットをOP構成から削除した。
- ルナとソラを成人として明記し、OP終盤も連れ去りを前提にしない文言へ変更した。戦闘、セーブ、課金、バランスは変更していない。

## 現在の年齢関連設定

- `ios/App/App/Info.plist`: 子供向け指定なし。
- `ios/App/App.xcodeproj/project.pbxproj`: iOS 15.0、iPhone/iPad対応。Kids Category指定なし。
- `data/characters.json`: プレイヤーキャラクターの年齢数値なし。「青年」は京介にのみ使用。
- App Store Connectの年齢レーティング値はソースから確認できないため、手動確認が必要。

## 暴力・流血表現

- 通常戦闘は様式化されたファンタジーRPG表現で、写実的な切断や拷問は確認されなかった。
- `assets/enemy-characters/dungeon4/fegoria.png` と `fegoria-form2.png` は血を思わせる赤黒い意匠がある。
- `assets/enemy-characters/dungeon5/d5-midboss-form1.png` はギターと衣装に血痕風表現がある。
- `js/data.js` の素材「夜獣の血」は説明に「血液」を含む。
- いずれも子供を対象にした表現ではないが、App Store Connectの暴力・ホラー・医療/血液関連質問には実表示頻度に合わせて正直に回答する。

## App Store Connectで手動変更・確認する項目

1. 「年齢制限指定」質問票を再回答し、13歳以上となる回答内容を確認する。
2. Kids Categoryを選択していないことを確認する。一度Kids Categoryとして公開済みの場合は変更制限があり得るため、App Store Connectサポートへ確認する。
3. 対象年齢や説明文に「子供向け」「ファミリー向け」「全年齢向け」などの表記がないことを確認する。
4. 暴力表現はファンタジー／アニメ調として、頻度を実態どおり回答する。
5. 血痕風の敵画像や「夜獣の血」が実際に表示されるため、血液・ホラー関連質問も過小申告しない。
6. 審査メモへ「ルナとソラを含む主要人物は成人であり、子供への暴力はない」「連れ去りは非写実的なファンタジー演出で、流血や身体的虐待を描かない」と明記する。
7. 審査返信では、問題とされた正確な画面または時刻の提示をAppleへ依頼する。

## 再審査前チェック

- 新規インストール状態で起動し、OPに成人表記が出ること。
- OPに連れ去り2カットが表示されず、終盤も連れ去りを前提にした文言が出ないこと。
- `pnpm run cap:sync` 後の `ios/App/App/public/js/start-flow.js` もソースと一致すること。
- App Store Connectの商品説明、スクリーンショット、プレビュー動画に未成年を示す文言がないこと。
- 年齢レーティング回答のスクリーンショットを保存してから再提出すること。

## 残存リスク

- アニメ調のルナ／ソラが見た目だけで若年に見える可能性は残るが、OP内で成人と明記した。
- Appleが成人明記後も人物画像自体を問題視した場合は、該当人物画像の差し替えが必要。
- App Store Connect側の過去のKids Category状態・現在の回答値はコードから検証できない。
