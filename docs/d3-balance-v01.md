# D3「崩界の深廊」バランス設計 Ver.0.1

## 目標

D2標準クリア直後からセリペス初回撃破まで、育成・装備製作・再挑戦を含めて6〜8時間を想定する。
戦闘回数だけで時間を延ばさず、階層ごとの能力差と役割編成で対策更新を促す。

通常戦は合計60勝。階層数は8だが、各階6〜9勝に抑えて階層数そのものでは時間を稼がない。

## 想定プレイ時間

人気ハクスラ／長期育成型の「戦闘で素材を得る → 装備を作る → ビルドを更新する → 高難度へ再挑戦する」という循環を基準に、初回クリアと収集完了を分離する。

| 遊び方 | 想定時間 | 内容 |
|---|---:|---|
| 熟練・最短攻略 | 5〜7時間 | 既存装備が整い、敵の役割を早期に把握できた場合 |
| 標準初回クリア | 8〜12時間 | 撤退、クラフト、JOB・武器学育成、ボス再挑戦を含む |
| RPGに不慣れ | 12〜18時間 | 5F以降で複数回撤退し、装備・JOBを段階的に整える場合 |
| セリペス安定撃破 | 10〜16時間 | 対策装備とパッシブを整え、再戦でも勝てる状態 |
| D3装備収集・図鑑 | 18〜30時間以上 | ★4ドロップ、クラフト、武器学・JOB育成を継続 |

標準初回クリアの内訳は、通常攻略2〜3時間、拠点・クラフト・装備比較1〜1.5時間、JOB／武器学／素材収集2〜3時間、ヴェルシクレル準備と再挑戦0.5〜1時間、セリペス準備と再挑戦2〜4時間を目安とする。セリペス区間が最大になるよう、単なるHP量だけでなく防御切替・再生・反奏への対策更新で時間が発生する構成とする。

## 調整点

- 各階の強さは `dungeons[dungeon3].floors[].enemyScale` で調整する。
- 戦闘回数は `winsToClear` で調整するが、時間調整の主軸にはしない。
- 前半4階を踏破するとヴェルシクレルが出現する。
- ヴェルシクレル撃破まで5F以降は解放しない。
- 全8階踏破後にのみセリペスが出現する。
- セリペスは専用BGMを持たず、共通ボスBGMを使用する。
- ヴェルシクレルのみ専用テーマ1・テーマ2を使用する。

## 次回テストで見る数値

- D2標準装備で1Fを安定突破できるか。
- 2〜4Fで回復役・防壁役の撃破順が実際に重要になるか。
- 5F到達直後に一度撤退してクラフトしたくなる強さか。
- 8Fが単純な即死ゲームにならず、装備更新の効果を体感できるか。
- セリペス戦がヴェルシクレルより明確に長く、最終準備の差が出るか。
