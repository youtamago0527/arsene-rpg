# ARSÈNE RPG 装備進行・強化・無限奏廊連携仕様書 v0.1

作成日: 2026-08-26  
状態: 設計案（未実装）

## 1. 結論

この方式で繰り返し運用できる。

- `★` は装備の入手難度・立ち位置を表す。
- `D段階` は、その装備が属するダンジョン帯の基礎性能を表す。
- `+値` は、同じ装備を重ねた育成度を表す。
- `OP` とランダム個体差は、無限奏廊から生還して持ち帰った装備だけに付く。

★とD段階を別軸にすることで、D1の★5が永久にD5の★2より強い、といった進行破綻を避けられる。

## 2. 星ランク

| 星 | 役割 | 主な入手 | 通常世界のOP | 基本方針 |
|---:|---|---|---|---|
| ★1 | 初期装備 | キャラ作成・初期配布 | なし | 最低限の性能。強化素材には使わない |
| ★2 | 標準装備 | 工房 | なし | 各Dの装備更新の中心。+7まで強化可能 |
| ★3 | 上級工房装備 | ★2装備＋レア素材 | なし | 同じDの対応★2+4相当を基礎性能にする |
| ★4 | 怪異・モンスター固有 | モンスタードロップ限定 | なし | 基礎戦闘値は同Dの★2+4程度。代わりに固有の基礎能力補正を持つ |
| ★5 | ボス装備 | ボス撃破・ボス素材 | なし | 同D最上位。基礎戦闘値とセット・固有効果の両方を持つ |
| ★6 | 虹・無限奏廊限定 | 無限奏廊の超低確率報酬 | あり | 通常工房・通常敵・通常ボスからは出ない。生還できた時だけ持ち帰れる最高希少個体 |

### ★3への進化

```text
対応する★2装備 + ダンジョン固有レア素材 + GOLD
→ 同系統の★3装備（+0）
```

- 素材にした★2の+値は引き継がない。
- ★3の基礎戦闘値そのものが、同Dの★2+4相当になる。
- 進化前装備を+4にすることを必須にはしない。必要素材数と費用で調整する。

これにより、「★2を強化して使い続ける」か「素材を集めて★3へ進化する」かを選べる。

## 3. ダンジョン段階

装備データには星とは別に `dungeonTier` を持たせる。

| 段階 | 内容 |
|---|---|
| D0 | 初期装備 |
| D1 | D1工房・D1怪異・D1ボス |
| D2 | D2工房・D2怪異・D2ボス |
| D3 | D3工房・D3怪異・D3ボス |
| D4以降 | 同じルールで追加 |

新しいダンジョンの★2は、前ダンジョン装備から自然に更新候補になる値にする。星だけで全ダンジョン共通の固定倍率を持たせない。

## 4. 強化値

### 基本式

```text
強化後戦闘値 = floor(装備の基礎戦闘値 × 1.2 ^ +値)
```

対象は次の直接戦闘値だけとする。

- ATK
- MAG ATK
- DEF
- MDEF

基礎能力補正、セット効果、固有効果、OPは+値で増幅しない。これらまで1.2倍にすると回避・会心・割合軽減などが壊れるため。

| 強化 | 倍率 | ★2基礎値20の例 |
|---:|---:|---:|
| +0 | 1.000 | 20 |
| +1 | 1.200 | 24 |
| +2 | 1.440 | 28 |
| +3 | 1.728 | 34 |
| +4 | 2.074 | 41 |
| +5 | 2.488 | 49 |
| +6 | 2.986 | 59 |
| +7 | 3.583 | 71 |

したがって、★3の基礎戦闘値は対応★2の約`2.074倍`を目安に作る。

### 強化上限と成功率（初期テスト値）

上限は全装備共通で+7。+4までは通常育成の確定帯、+5からは本体破壊リスクのある挑戦帯、+7は最終到達枠とする。+7成功率を星ごとに6〜20%へ分ける。

| 到達先 | ★2 | ★3 | ★4 | ★5・★6 |
|---:|---:|---:|---:|---:|
| +1 | 100% | 100% | 100% | 100% |
| +2 | 100% | 100% | 100% | 100% |
| +3 | 100% | 100% | 100% | 100% |
| +4 | 100% | 100% | 100% | 100% |
| +5 | 70% | 60% | 50% | 40% |
| +6 | 45% | 35% | 25% | 18% |
| +7 | 20% | 15% | 10% | 6% |

成功率・費用・必要素材数はデータ化し、星ごとに変更可能にする。

### 失敗時

- ベース装備をロストする。
- ベース装備に付いていた+値、個体差、OPも一緒に消滅する。
- 素材にした同名装備1個とGOLDも消費する。
- 装備中の品を強化して失敗した場合は、その装備部位を自動的に外す。
- ロスト前に、対象名・現在の+値・OP・成功率を確認画面へ明記する。

この大きなロストリスクは、無限奏廊限定アイテム《強化保護のアルカナ》（仮称）で回避できる。

### 《強化保護のアルカナ》（仮称）

- 無限奏廊だけで入手でき、生還した場合のみ通常世界へ持ち帰れる。
- 強化対象と素材が揃い、1個以上所持している場合、強化ボタン押下後に使用確認を出す。

```text
《強化保護のアルカナ》を使用しますか？
失敗してもベース装備と現在の強化値・OPを保護します。

［使用して強化］［使用せず強化］［戻る］
```

- 「使用して強化」を選び、失敗した時だけ1個消費する。
- 失敗してもベース装備、現在の+値、個体差、OPを維持する。
- 強化素材とGOLDは戻らない。
- 成功した場合、アルカナは消費しない。
- 「使用せず強化」で失敗した場合は、通常どおりベース装備ごとロストする。
- 未所持の場合はこの確認を出さず、通常のロスト警告だけを出す。

## 5. 星ごとの性能目標

同じD・同じ装備系統で比較する。

| 星 | 直接戦闘値の目安 | 追加価値 |
|---:|---|---|
| ★1 | D0初期値 | なし |
| ★2 | そのDの基準値 | 安価・作りやすい・+7を狙いやすい |
| ★3 | 対応★2+4相当 | 工房で確実に目指せる上級品 |
| ★4 | 対応★2+4相当 | モンスター由来のSTR/AGI/MAG等、ビルド用基礎能力 |
| ★5 | 対応★2+6相当を上限目安 | ボス固有効果・セット効果 |
| ★6 | 元装備と深度に応じる | 無限奏廊限定の高品質個体・高Rank OP・虹演出 |

★4は単純な★3の完全上位にしない。★3は直接戦闘値と強化しやすさ、★4は基礎能力と特化ビルドで差別化する。

★5は最上位だが、すべてのJOBで常に最適にはしない。ボスのテーマに合うJOB・武器・戦術で強くなる設計にする。

## 5.1 ★3・★4・★5の入手速度

平均的な入手順序は必ず次の順にする。

```text
★2工房品 → ★3製作 → ★4怪異現物 → ★5ボス現物
```

運よく★4・★5が先に出る可能性は残す。ただし、通常プレイの80%以上で★3を先に1個製作できることを目標にする。

### ★4怪異装備の基礎ドロップ率

対象装備を持つ該当モンスターを倒した時だけ抽選する。

| ダンジョン | 現在値 | 初期テスト値 | 単純期待撃破数 |
|---|---:|---:|---:|
| D1 | 4.0% | 1.20% | 約84体 |
| D2 | 1.8% | 0.70% | 約143体 |
| D3 | 0.8% | 0.40% | 250体 |

- 「該当モンスターの撃破数」であり、全戦闘数ではない。
- ★3製作時間の実測後、`★3を先に作れる割合80%以上`になるよう再調整する。
- ★4率は敵ごとの個別データではなく、D別基準値＋敵固有補正として管理する。
- レア敵や出現率の低い敵は、同じDでも基準値を少し上げてよい。
- 救済が必要になった場合はドロップ率を大きく上げず、同一怪異の撃破数による天井を別途検討する。

### ★5ボス装備の現物ドロップ

ボス撃破時の素材報酬と別に、シリーズ装備の現物抽選を行う。現物は工房製作を飛ばせる大当たり枠であり、★4より低い確率にする。

| ダンジョン | ボス現物枠 | 単純期待ボス撃破数 |
|---|---:|---:|
| D1 | 0.60% | 約167回 |
| D2 | 0.35% | 約286回 |
| D3 | 0.20% | 500回 |

- 当選時は対応ボスシリーズから現物1個を抽選する。
- 同一戦闘で現物は最大1個。
- ボスの能力2倍化を前提に、現物だけで一式を集めるのは非常に難しくする。
- 一式完成の主経路は、従来どおり確定欠片・確率コアを集める工房製作とする。
- 現物は重複しても、分解して対応するボス欠片へ変換できる。
- 初回撃破のSCORE、証、キーアイテム、レシピ解放はこの抽選と無関係に確定付与する。

### レア装備へのドロップ率補正

通常素材に使う固定加算を、★4・★5現物へそのまま適用しない。

```text
通常素材:
実効率 = 基礎率 + 固定ドロップ補正

★4・★5現物:
実効率 = 基礎率 × (1 + レア装備ドロップ補正)
```

例えば通常ドロップ率+2%のキャラクター特性は、レア装備に対して初期値では`+20%相対補正`へ変換する。

```text
D3 ★4: 0.40% × 1.20 = 0.48%
D3 ★5: 0.20% × 1.20 = 0.24%
```

これによりドロップ特化キャラの価値は残しながら、0.4%が2.4%へ跳ね上がる逆転を防ぐ。

## 6. 無限奏廊の装備

### 基本方針

無限奏廊専用の装備名を大量に増やさず、通常世界に存在する装備を抽選する。

- 通常抽選では元装備の星を維持する。別枠の超低確率抽選に当選した個体だけ★6へ昇格する。
- 通常装備と同じ `baseItemId` を持つ別個体として生成する。
- 個体ごとに小さな基礎値乱数と最大4枠のOPを持てる。
- OP付き装備を通常世界で新規製作することはできない。
- 生還して持ち帰った時だけ通常所持品へ移動する。

### 個体差

```text
個体基礎戦闘値 = floor(通常品基礎戦闘値 × qualityRoll)
初期 qualityRoll = 0.95 ～ 1.05
```

深層や品質上昇カードで範囲・下限を少し上げてもよい。ただし、現在の無限奏廊にある最大2.20倍の独立レアリティ倍率は、通常世界の★序列と競合するため置き換える。

### ★6抽選

- ★6は無限奏廊内の超低確率抽選、深層宝箱、レア敵、特殊カードからだけ出現する。
- 元になる通常装備の `baseItemId` は維持し、生成個体だけを★6へ昇格させる。
- 通常工房での製作、通常敵・通常ボスからのドロップ、★5以下からの進化は不可。
- RETURNまたは生還前に死亡した場合は、他の戦利品と同様にロストする。
- 浅層にも極低確率の夢枠を残し、深層ほど抽選率を上げる。
- 直接戦闘値だけを極端に増やさず、高い品質下限、OP枠、OP Rank、虹演出で価値を作る。
- 出現率、最低階層、品質範囲、OP数、OP Rankは無限奏廊DEBUGから変更可能にする。

### OP

- OPは無限奏廊由来装備だけに付く。
- 最大4枠。
- OP値は+値の1.2倍対象外。
- 同じOP同士を合体すると1Rank上昇。
- 空き枠があれば異なるOPを1個選んで継承。
- 最大Rankでは上昇しない。
- OP削除後はEMPTY枠になる。

### 通常品を素材にした強化

持ち帰ったOP付き装備は、通常世界で作った同一 `baseItemId` の装備を素材にして+1できる。

- 通常品にOPが無ければ、OPは変化せず+値だけ上がる。
- OP付き同士なら既存の同一OP強化・空き枠継承ルールを使う。
- ベース側の `qualityRoll` は維持する。
- 素材側の `qualityRoll` は引き継がない。

### 階層ごとの抽選プール（初期案）

| 階層 | 通常ドロップ候補 |
|---:|---|
| 1F〜10F | D1の★1〜3、D2の★2。別枠で★6の超低確率抽選 |
| 11F〜20F | D1〜D2の★2〜3 |
| 21F〜30F | D2〜D3の★2〜3 |
| 31F以降 | 到達済み通常Dの★2〜3を中心に段階拡張 |

- 通常プールから★4怪異装備・★5ボス装備は除外する。
- ★4・★5を入れる場合は、将来の専用レアイベントだけに限定する。
- ★6は通常プールと分離した無限奏廊限定抽選として処理する。
- 未解放ダンジョン・未公開武器種は抽選しない。

## 7. 推奨データ構造

### 通常装備

```js
{
  id: 'exampleSword',
  name: '例の剣',
  dungeonTier: 'D2',
  stars: 2,
  sourceType: 'workshop',
  evolutionFrom: null,
  attackPower: 20,
  magicAttackPower: 0,
  defensePower: 0,
  magicDefensePower: 0,
  bonuses: {},
  effects: {},
  enchantCap: 6
}
```

### 無限奏廊の個体

```js
{
  uid: 'run-gear-...',
  baseItemId: 'exampleSword',
  origin: 'infiniteScore',
  qualityRoll: 1.034,
  plus: 2,
  ops: [
    { key: 'criticalRateBonus', rank: 2, value: 0.06 }
  ]
}
```

`baseItemId` と個体UIDを分離する。現在の通常所持品はIDごとの個数管理なので、OP付き個体を持ち帰るにはインスタンス装備用の保存領域が必要。

## 8. 工房UI

### ダンジョン別アコーディオン

```text
▼ D1装備
  武器 / 頭 / 体 / アクセ
▶ D2装備
▶ D3装備
```

- 初期表示は現在進行中のDだけ開く。
- 装備数が増えても縦に全件展開しない。
- アコーディオン内は武器種または装備部位で絞り込める。
- 未解放Dと未解放武器種は存在自体を表示しない。

### 比較表示

選択中装備と現在装備を、強化反映後の実効値で比較する。

```text
攻撃力       42 → 51  +9
魔法攻撃力    0 →  0   0
防御力       18 → 14  -4
STR           2 →  4  +2
AGI           3 →  1  -2
```

表示対象:

- ATK / MAG ATK / DEF / MDEF
- 最大HP / 最大MP
- STR / VIT / MAG / MND / AGI / DEX / LUK
- 会心・命中・回避などの割合
- 固有効果・セット効果
- OPとOP Rank
- 基礎値、個体差、+値、最終値

上昇は緑、低下は赤、変化なしは灰。基礎能力補正を省略しない。

## 10. 実装順

1. 全現行装備へ `dungeonTier / stars / sourceType` を確定。
2. 強化上限を+7、倍率を`1.2^n`へ変更。
3. +5以降のベースロストと《強化保護のアルカナ》確認・保護処理を実装。
4. ★2→★3進化レシピと性能基準を統一。
5. ★4と★5現物を専用レア抽選へ分離し、固定ドロップ補正を相対補正へ変換。
6. 工房をD別アコーディオン化し、完全比較表示を追加。
7. 無限奏廊を`baseItemId + qualityRoll + OP`方式へ移行。
8. 無限奏廊の階層プールを制限。
9. 無限奏廊限定★6抽選と虹表示を追加。
10. Monte CarloでDごとの★3先行率・撃破速度・被ダメ・更新頻度を再計測。

## 11. 調整時に見る数値

- 各Dで★2を作るまでの平均戦闘数。
- ★3を1個作るまでの平均時間。
- ★4を1個得るまでの戦闘数とJOB適合率。
- ★5一式までの周回数。
- +4 / +5 / +6の到達率と消費コピー数。
- 新D★2が前D★3〜5を更新する割合。
- 無限奏廊1RUNあたりのOP付き持ち帰り数。
- 通常品がOP付き装備の強化素材として無駄なく使われる割合。

最終判断は星の見た目ではなく、通常プレイでの装備更新頻度とJOB別ランキングで行う。
