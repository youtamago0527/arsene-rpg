## 3. 起動・開始フロー

1. オープニングを再生する。SKIP可能。
2. 6人から主人公を選択する。
3. 名前を入力する。空欄時はキャラクター既定名、最大12文字。
4. 初期JOBと初期武器を選択する。
5. 拠点へ入り、ダンジョン・料理・装備・JOB・所持品・図鑑・設定を利用する。

CONTINUEは端末内セーブを読み込む。設定からセーブコードを書き出し、別ブラウザ・別URL・別端末へ読み込める。

## 5. 基本ゲームループ

1. 拠点でJOB・装備・料理・消耗品を準備する。
2. ダンジョンで通常戦を重ね、階層またはイベント条件を満たす。
3. 中ボス・最終ボスを倒す。
4. EXP、JOB EXP、武器学EXP、GOLD、素材、装備を得る。
5. 工房で製作・強化・分解する。
6. 新JOB・武器種・転生・曜日異世界ダンジョン・無限奏廊を順次解放する。

通常潜入で敗北または拠点帰還すると、その潜入用料理バフは消滅する。通常の育成・所持品・装備・解放状態は保存される。

- アスタクト戦前: 主人公の遅さを指摘し、一拍の隙でリズムを奪うと宣言する。撃破後は自らが一拍遅れたことを認める。
- オスティナ戦前: D1〜D4の突破を列挙し、主人公たちは何者かに導かれていると示唆する。撃破後は扉・鍵・導き手の存在を示唆して先へ進ませる。

## 7. 戦闘

### 7.1 ターンと操作

- コマンド選択式。基本順序はプレイヤーACTION後に敵ACTION。
- コマンド: たたかう、武器技、JOB/キャラクタースキル、防御、アイテム、リピート、一掃、AUTO。
- 防御はそのラウンドに受ける最終ダメージを50%軽減する。
- リピートは直前の再実行可能な行動を繰り返す。
- 敵本体タップで対象選択。状態欄タップで効果詳細を表示する。
- 逃走可能な通常戦と、逃走不可のボス戦を分ける。

### 7.2 AUTO

- `OFF → ×1.5 → ×2 → OFF`。
- 勝利後もAUTO ONと倍率を次の戦闘へ保持する。
- 敗北・拠点帰還では解除する。
- HP40%未満なら回復薬、MP20%未満なら魔力回復薬を優先する。
- 無限奏廊では通常所持品ではなくLOOT BAG内の回復薬だけを使う。
- 使用可能な技を威力、対象数、回復必要度、MP、装備条件、CTから選ぶ。

### 7.3 命中・会心

```text
基本命中率 = 90% + 攻撃側DEX×0.6% - 防御側AGI×0.5%
最終命中率 = 5%〜100%
基本会心率 = 6% + LUK×0.8%
通常会心上限 = 28%
会心ダメージ = 1.65倍
```

体術・楽器は命中+5%、盾は命中-10%。必中技は命中判定を省略する。

### 7.4 被ダメージ

```text
物理基礎 = 敵ATK×0.70×40/(40+物理防御)
魔法基礎 = 敵MAG×0.78×40/(40+魔法防御)
敵側乱数 = -1〜+2
最低ダメージ = 1
```

物理防御はVITと装備DEF、魔法防御はMNDと装備MDEFを参照する。

## 9. 成長・武器学・Spark

- HP基本成長率15%、MP基本成長率8%。
- HP成長量1〜5、MP成長量1〜3。
- JOB・キャラクター適性で確率を補正する。
- 武器を使った1ACTIONごとに武器学EXPを得る。多段攻撃でも1ACTIONにつき1回。
- 次の武器学Lvまで `20 + 現在Lv×5` EXP。
- 武器学Lv1ごとに対応武器の最終ダメージ+0.5%。
- 原則1戦闘で武器学LvUPは1回まで。

Spark基本率は敵Spark Lvと武器学Lvの差により15/12/8/5/2/1/0.5/0%。通常攻撃由来×0.25、関連技由来×0.5、直接派生×2.0。初回Sparkは元行動と入れ替わって発動し、追加MPを消費しない。

- 通常JOBは他JOBのACTIONを装備できない。
- 習得ACTION/PASSIVEは転生後も維持する。
- 通常MASTER基準は現在解放中の上限。初期はLv20、セリペス初回撃破後はLv40、オスティナ初回撃破後はLv70へ段階的に移る。上限解放時は全通常JOBのMASTER認定を一度解除し、新上限到達時に再認定する。既に盗んだ固有ACTIONは維持する。Lv21以降の成長量は2倍。

### 10.3 転生

- 条件: 通常JOB Lv20以上、輪廻のアルカナ1個。

### 10.4 PHANTOM THIEF

## 14. 無限奏廊

### 14.1 解放と終了

- セリペス撃破で解放し、PHANTOM THIEF解放も必要。
- 最大FLOOR 9999。
- 20F未満ではRETURNを入手できない。
- 20F到達後の初回勝利で、未所持ならRETURNを1個保証する。
- RETURN使用で戦利品を持ち帰る。
- 全滅すると持込品・取得品を全ロストする。基礎能力、JOB、転生、武器学、習得技、RE:MIXは失わない。

### 14.2 敵倍率と想定壁

```text
敵倍率 = 1 + (FLOOR - 1) × 0.16
```

| FLOOR | 倍率 |
|---:|---:|
| 1 | 1.00 |
| 10 | 2.44 |
| 20 | 4.04 |
| 50 | 8.84 |
| 100 | 16.84 |

D3クリア直後では20Fが壁、D5クリア相当で20F到達が現実的になる設計基準。敵原種も変わり、1〜4FはD1初期、5〜10FはD1全般、11〜15FはD2、16F以降はD3系。希少敵は16F以降に出る。

### 14.3 探索

- 1階は8行×3列のマップ。
- 戦闘、宝箱、罠、アイテム、奏貨、ショップ、工房、希少敵が発生する。
- 有効イベント重み: 戦闘87、宝箱18、罠10、アイテム10、奏貨10、ショップ2、工房3、希少3.5。重み合計で正規化して抽選するため、ショップの実効割合は初期状態で約1.4%。
- ショップ設定値は2（旧設定8の1/4）。工房重みは25階ごとに上昇し最大6。
- 階段発見率は15%から抽選ごとに+15%、最大100%。
- 宝箱は木70%、銀25%、金5%。
- レア敵率3.5%、装備基礎ドロップ率14%、回復薬ドロップ率5%、RETURN追加率0.8%。
- 装備ドロップ率は階層ごとに+0.4%、最大95%。
- 奏命カードは探索イベントでは抽選せず、勝利後20%でのみ3択を表示する。旧カードイベント重み45は探索イベント総数を変えないため戦闘重みへ統合しており、勝利後抽選には使用しない。二重抽選は行わない。

### 14.4 LOOT BAG

- 基本30枠。
- 装備中の品も枠を使う。
- 無限内では同一消耗品もスタックせず、1個=1枠。
- 通常所持品から複数持ち込む場合も1個ずつ別枠。
- 帰還後は通常所持品へ数量として再スタックする。
- バッグ満杯時は取得品を捨てるか既存品を捨てて入れ替える。

## 15. 無限装備・異世界工房

奏貨は無限奏廊のショップと異世界工房で共通利用するRUN内通貨。通常GOLDとは分離し、RETURN帰還・全滅のどちらでもRUN終了時に消滅する。

### 15.1 個体装備

- 同一アイテムIDでも個体ごとに品質、レアリティ、OP、強化値、UIDを持つ。
- レアリティ率: COMMON 55%、RARE 27%、EPIC 12%、LEGENDARY 5%、MYTHIC 1%。
- 品質倍率: 1.00〜1.10 / 1.15〜1.30 / 1.35〜1.55 / 1.60〜1.85 / 1.90〜2.20。
- OP枠: 0〜1 / 1〜2 / 2〜3 / 3〜4 / 4。
- ロック、並べ替え、装備中表示、通常装備との比較に対応する。

### 15.2 調律

- 異界の欠片を消費し+1。+6以降は異界の核も必要。
- +3までは100%。+4以降は失敗で装備消滅。
- 保護のアルカナで消滅を防止できる。
- 基礎戦闘値は調律+1ごとに8%上昇。OP・割合効果・セット効果は増幅しない。
- 成功率: +4 85%、+5 70%、+6 55%、+7 42%、+8 32%、+9 24%、+10 18%、+11以降は1段階ごと-2%、最低5%。

### 15.3 OP加工

- OP移植: 移植元装備消滅、1個だけ移植、同系統装備間、成功率100%。移植先★上限を超えるRankは切り下げる。
- OP削除: 異界の欠片10個。
- 同型合成: 同型素材装備を消費する。
- 昇華: 任意OPを1Rank上げる。上限を超えない。
- 固有奏技は通常OP移植対象外。

## 16. リワード広告

### 16.1 共通原則

- 広告視聴は任意。視聴しなくても通常進行できる。
- 報酬イベント受信時だけ成功扱い。
- 途中閉じ、ロード失敗、表示失敗、タイムアウトは報酬なし・利用回数を消費しない。
- 多重押下を防止し、報酬は1回だけ付与する。

### 16.2 無限奏廊の広告支援

| 支援 | 制限 |
|---|---|
| ショップ候補再抽選 | 1ショップ1回 |
| 全滅時の装備1個奪還 | 1RUN1回 |
| バッグ緊急拡張 | 1RUN1回、30→33枠 |

ブラウザ版はネイティブプラグインを呼ばない。iOS版だけAdMobを使用する。広告スキップ権がある場合も効果と回数は同じ。

### 16.3 審査準備差分

現在の公開iOSブランチはGoogle公式デモApp ID・デモRewarded ID。審査前に本番IDへ差し替える。審査初期は非パーソナライズ広告中心とする。準備ブランチではUMP同意情報を起動ごとに取得し、`canRequestAds`がtrueの場合だけ広告を要求する。タイトル設定と拠点設定からプライバシー選択を再表示できる。

## 17. セーブ

- localStorageキー: `arsene-rpg-save-v01`。
- 現行セーブバージョン: 19。
- 旧セーブはロード時に不足項目を補完し、旧ラーメンID等も現行IDへ移行する。

## 19. UI・アプリ仕様

- PC・スマートフォン対応。iOSはCapacitor 8.5.0。
- iPhone/iPadとも縦向き固定。
- native画面は`100dvh`で固定し、ページ全体のスクロール・バウンス・ピンチ拡大を禁止する。
- 長い一覧とモーダル内部だけスクロール可能。
- `viewport-fit=cover`とSafe Areaを使用し、Dynamic Island、ノッチ、ホームインジケーターを避ける。
- 320×568、375×812を最低基準として主要画面の横はみ出しを防ぐ。
- 背景は画面端まで描画可能、操作要素はSafe Area内。
- バックグラウンド復帰時に音声多重再生・入力停止を起こさないことを実機確認項目とする。
- Webアセットは`dist`へ生成後、`ios/App/App/public`へCapacitor同期する。
