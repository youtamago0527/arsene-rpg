# 無限奏廊 装備OP一覧

装備Ver.2で抽選される全63種。グレードはOPの等級で、装備のレアリティごとに抽選比率と枠数が決まる。各効果のプログラム上の定義は `js/infinite_gear_v2_data.js` を参照。

- 「値」の欄が「装備レア依存」のときは、COMMON 3〜10%、RARE 15〜25%、EPIC 30〜45%、LEGEND 50〜65%、MYTHIC 70〜90%。INFINITYでは入手階×1%に乱数の上振れを加える。
- 経験値UPとGOLD UPは表の基準値に乱数の上振れを加える。INFINITYの最低値は入手階×1%。
- 装備のOP枠はCOMMONから順に1、1〜2、2〜3、3〜4、4〜5、6。表で複数枠対応と記したOPは同名で重ねられる。
- 属性追撃は40階以上で抽選され、40階未満で得た装備には移植できない。右手とアクセを追撃に特化させると、元の1ヒットと合わせて最大13ヒット。追撃は元のヒットで命中した場合に発生し、命中・会心・追加の発動効果を個別に抽選しない。弱点倍率は対応する属性追撃に掛かる。
- 旧防具・小盾に保存されていた「追加ダメージ」は残る。12枠の上限に達する場合、右手とアクセの追撃を優先する。
