## 判定基準

- 画面本体は縦向きviewportへ固定し、ページ全体をスクロールさせない。
- 長い一覧とモーダル内部だけをスクロール可能にする。
- 操作要素はSafe Area内へ収め、背景画像だけは端まで描画してよい。
- 320 CSS px幅でも主要操作が欠けず、横スクロールを必須にしない。
