# 武器学・閃きシステム監査レポート v0.1

対象データ: 武器技21種 / 本体敵48種＋異世界追加敵7種（実行時合計55種）  
検証日: 2026-08-22

## 結論

- 全21武器技は `source: weapon` と `sparkRank` を持ち、JOB固有ACTIONは混入していない。
- 《ばくれつけん》は `source: job` のままで、閃き候補・派生元の双方から除外されている。
- 通常攻撃は対応武器の全技へ一律 `×0.25`、同系統の関連技は `×0.50`、正規派生だけ `×2.00`。
- 旧Lvによる完全ロックは廃止済み。Spark Scoreが-30以下の場合だけデータ表に従って0%。
- 本体48敵と後読み込みの異世界7敵、実行時合計55敵すべてにSpark Levelが設定されている。レア《メロクス》はSpark Lv.34で、通常雑魚より明確に高い。
- 性能監査により、低Rankながら多段・会心・防御効果を持つ3技をRank 5から7へ調整した。
- 《リコーダーでチョーキングぅう！？》は実データMP3に対して説明だけ「MP消費なし」になっていたため、初回閃き時だけ追加MP0という現仕様に合わせて説明を修正した。

### 派生補足

- 《影縫い》は《疾風拳》から×2.0、《急所突き》からは関連技扱い×0.5。
- 《インフェルノ》は《ファイアストーム》から×2.0、《ファイアランス》からは×0.5。
- 《プレシャススカイ》は専用ギター装備時だけ候補へ入り、通常攻撃×0.25・同楽器技×0.5で抽選する。
- 現行技には `sparkExclusive: true` を使用していない。

### シミュレーション所見

1. 武器学倍率は全武器へ同じ最終乗算で入り、Lv20×1.10 / Lv50×1.25 / Lv100×1.50 / Lv200×2.00が崩れていない。
2. Lv上昇だけで武器種の順位が大きく逆転しない。武器学が既存の武器個性を壊していない。
3. 楽器が首位なのは、固定ビルドのDEX165と《掃除棒攻撃》の2.2倍＋会心25%が噛み合うため。Rank 40相当の奥義性能として整合する。
4. 杖はMAG230と単体1.6倍で安定して2位。魔法型ビルドとして自然。
5. D3では高DEFの影響で、DEF/MDEFを攻撃へ変える盾が剣・体術を上回る。守護士の「受けて返す」役割が数式上も出ている。
6. 剣と体術はD3高防御相手でほぼ同水準。今後の装備・JOB・弱点・追加効果で差別化する余地があり、武器学倍率自体に個別補正を追加する必要はない。

## 今後の調整基準

- 初級でも多段・全体・高会心・強い防御効果がある場合はRankを2〜5程度上げる。
- 全体＋状態異常、全体＋回復、必中全体は同じ旧習得Lvの単体技より高Rankにする。
- 新しいレア敵は同階層通常上限より2〜5高いSpark Levelを目安とする。
- Rank/Level調整は `js/data.js` の `weaponSparkDefinitions` / `enemySparkLevels` だけで行う。
- 実戦確率はDEBUG ROOMのSpark計算機で確認してから反映する。
