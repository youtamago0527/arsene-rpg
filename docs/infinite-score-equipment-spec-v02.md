# 無限奏廊・異世界装備仕様 v0.2

作成日: 2026-09-02  
状態: 再設計・実装基準

## 1. 方針

旧案の「既存装備へランダム倍率とOPを付与する方式」は廃止する。

- 無限奏廊では、通常装備とIDが重ならない《異世界シリーズ》だけが落ちる。
- 強化素材に同名装備は要求しない。曜日ダンジョンで入手する《異界の欠片》を使う。
- 通常工房の強化値・同名素材合成とは完全に分離する。
- 同じ星・同じ名前でも基礎性能に個体値を持たせ、《当たり個体》を厳選できるようにする。
- ランダム性はドロップする星、基礎個体値、付与OP、OPランクへ集約する。

専用装備IDと個体UIDを併用し、通常工房の強化値とは衝突させない。

## 2. 装備系列

異世界シリーズは星ごとに別ID・別名称・別性能とする。

| 星 | シリーズ仮称 | 役割 |
|---:|---|---|
| ★3 | 境界シリーズ | 無限奏廊の導入装備 |
| ★4 | 深界シリーズ | 中層の主力装備 |
| ★5 | 幻奏シリーズ | 深層の上位装備 |
| ★6 | 無限シリーズ | 最深部の希少装備 |

各シリーズに次の部位を用意する。

- 剣・体術・杖・楽器・盾
- 頭・身体・腕・足・アクセサリー

★が上がるほど基礎性能とOP上限が上がる。同じ装備でも個体値によって基礎性能が変わる。

## 3. 階層別ドロップ

深くなるほど★3と★4が減り、★5と★6が逆転して増える。

| FLOOR | ★3 | ★4 | ★5 | ★6 |
|---:|---:|---:|---:|---:|
| 1–9 | 82% | 16% | 2% | 0% |
| 10–24 | 60% | 32% | 7.5% | 0.5% |
| 25–49 | 35% | 45% | 18% | 2% |
| 50–99 | 15% | 40% | 38% | 7% |
| 100–149 | 5% | 25% | 55% | 15% |
| 150以降 | 0% | 10% | 60% | 30% |

表の確率は「装備ドロップが成立した後」の星抽選。装備自体のドロップ率は敵、宝箱、階層イベントで別に設定する。

### 基礎個体値

各装備はドロップ時に、主要な基礎戦闘値へ共通の個体倍率を持つ。画面では倍率ではなく《品質 87～120》として表示する。

| FLOOR | 品質抽選範囲 |
|---:|---:|
| 1–24 | 87～105 |
| 25–49 | 90～110 |
| 50–99 | 94～115 |
| 100–149 | 97～118 |
| 150以降 | 100～120 |

- 品質100でシリーズ標準性能。
- 品質120が最高個体。
- 強化後も品質は変化しない。
- 品質は攻撃力、防御力、魔法攻撃力、魔法防御力へ適用する。
- HP、能力値、会心率、割合効果へ品質倍率を掛けない。

## 4. OP

- ★3: 0～1枠、最大R2
- ★4: 1～2枠、最大R3
- ★5: 2～3枠、最大R4
- ★6: 3～4枠、通常最大R5。FLOOR 150以降のみ極低確率でR6
- 同一装備へ同じOPは重複しない。
- OPは装備の基礎性能とは別加算とし、通常強化倍率を掛けない。
- OP付き装備は同名でも個体差が発生するため、帰還時には《異世界装備庫》で個体管理する。
- 通常インベントリの同名装備個数には加算しない。

### OPプール

異世界OPはエンドコンテンツの集大成として、戦闘・育成・収集・探索に関係するほぼすべての効果を抽選対象にする。OP定義はデータ配列化し、後から効果を追加しても生成・表示・保存処理を変更しなくてよい構造にする。

| 系統 | OP例 |
|---|---|
| 基礎能力 | 力、体力、魔力、精神、素早さ、器用さ、運、最大HP、最大MP |
| 直接戦闘値 | 攻撃力、防御力、魔法攻撃力、魔法防御力、命中、回避、会心率、会心威力 |
| 与ダメージ | 物理、魔法、通常攻撃、技、単体、全体、連撃、瀕死時、満タン時の与ダメージUP |
| 属性 | 炎・氷・雷・風・光・闇・虚属性ダメージ、属性耐性、弱点倍率 |
| 防御 | 物理軽減、魔法軽減、属性軽減、ガード率、瀕死軽減、満タン時軽減 |
| HP・MP | HP吸収、MP吸収、戦闘後回復、ターン回復、消費MP軽減、確率でMP消費なし |
| 行動 | 追加攻撃、反撃、先制率、再行動、技再演、クールダウン短縮 |
| 状態 | 毒・暗闇・沈黙・弱体の付与率、状態耐性、弱体持続延長 |
| 育成 | EXP UP、JOB EXP UP、武器学EXP UP、Spark成長率UP、HP成長抽選補正 |
| 収集 | GOLD UP、素材ドロップUP、装備ドロップUP、レアドロップUP、アルカナ率UP |
| 無限探索 | 奏貨UP、宝箱率UP、金宝箱率UP、レア敵率UP、RETURN率UP、罠軽減、バッグ枠UP、階段発見率UP |
| 条件付き | 敵数、現在HP、経過ターン、連勝数、FLOOR、装備中セット数に応じた強化 |
| JOB連動 | JOB固有技の威力・回復量・持続・命中・消費MPを個別強化 |

### OP抽選規則

- 装備部位による完全な抽選禁止は設けず、どの部位にも意外な当たりを作る。
- 同じOPは1個体内で重複しない。
- 通常値OPと希少OPを分け、強力な効果ほど抽選重みを低くする。
- OP値とランクは別抽選。同じR4でも範囲内に個体差を持たせる。
- 深層ほど高Rankの最低値と希少OPの抽選率が上昇する。
- 効果が現在モードで無効な場合も装備詳細へ明記する。
- 複数装備のOPは原則加算するが、確率・軽減・追加行動には個別上限を設ける。

### OPランク

| Rank | 位置付け | 主な入手 |
|---:|---|---|
| R1 | 小さな補助 | 浅層全般 |
| R2 | 実感できる補助 | ★3～ |
| R3 | ビルドの一部 | ★4～ |
| R4 | 主力効果 | ★5～ |
| R5 | ビルド中核 | ★6・深層 |
| R6 | 神話OP | FLOOR 150以降の★6へ極低確率 |

### 暴走防止上限

やり込み価値は残しつつ、100%化でゲームが停止しないよう最終合算値だけ制限する。

- 追加行動・技再演: 合計30%
- MP消費なし: 合計50%
- 物理・魔法軽減: セット込み合計80%
- 回避率: 合計75%
- RETURN率: 基礎値込み最大15%
- 階段発見率: 1回の抽選最大95%
- EXP、JOB EXP、武器学EXP、GOLD、通常素材ドロップは上限なし
- レア装備・固有奏技・最高Rank OPの抽選率は個別に上限を持つ

### OPによる装備名変化

希少OPや固有奏技を持つ装備は接頭語・接尾語が付き、星が上がるほど名称演出も強くする。

- ★3: 《剛力の》境界剣
- ★4: 深界剣アビス《強欲》
- ★5: 幻奏剣《ノクターン・レクイエム》
- ★6: 終奏神器《インフィニティ》— 神喰らい

内部の `itemId` は変えず、表示名だけをOPと固有奏技から生成する。

### 固有奏技

通常OPとは別枠で、極低確率の《固有奏技》を持つ個体がドロップする。

- 固有奏技は通常OP枠を消費しない。
- 移植、抽出、再抽選、削除、ランクアップ不可。
- 装備中だけ有効。外すと使用できない。
- 習得技一覧へ恒久登録しない。
- 同じ固有奏技を複数装備しても重複発動しない。
- 装備ロスト時は固有奏技も失われる。
- 《保護のアルカナ》で強化失敗時の消滅を防げる。
- 固有奏技付き個体は専用色、アイコン、入手演出を付ける。

| 星 | 固有奏技付与率 |
|---:|---:|
| ★3 | 0% |
| ★4 | 0.5% |
| ★5 | 3% |
| ★6 | 8% |

武器には戦闘コマンドへ追加されるACTIVE、盾・防具・アクセサリーには常時または条件発動のPASSIVEを中心に付ける。

固有奏技の仮案:

- 剣《境界断ち》: 単体物理攻撃。敵HPが30%以下なら威力上昇。
- 体術《無拍子》: MPを使わず、低威力の3連撃。
- 杖《深淵詠唱》: 全体魔法攻撃。使用後に自身の魔法防御低下。
- 楽器《幻奏再演》: 直前に使った攻撃技を低威力で再演。
- 盾《反界》: 防御成功時、一定確率で受けた一部を反射。
- 頭《透界視》: 宝箱とレア分岐の気配表示を一段階正確にする。
- 身体《不帰の残響》: HP30%以下で被ダメージ軽減。
- 腕《奪奏》: 攻撃時、低確率で奏貨を追加獲得。
- 足《境界歩法》: 逃走成功率上昇。
- 装飾《帰還律》: RETURN出現率をわずかに上昇。

## 5. 調律強化

異世界装備の強化名は通常工房と区別して《調律》とする。

- 素材: 曜日ダンジョンの《異界の欠片》
- 補助素材: 上位段階で《異界の核》を使用
- 同名装備は不要
- 強化上限なし
- +3までは必ず成功
- +4以降は失敗すると強化対象が消滅
- 《保護のアルカナ》を使うと、失敗しても装備と現在の+値を維持できる
- 保護時も使用した異界素材は戻らない
- 強化対象は基礎戦闘値のみ。OP、割合効果、セット効果は増幅しない

| 星 | +1ごとの異界の欠片 | +6以降の異界の核 |
|---:|---:|---:|
| ★3 | 3 + 現在値×2 | 1個 |
| ★4 | 5 + 現在値×3 | 1個 |
| ★5 | 8 + 現在値×4 | 2個 |
| ★6 | 12 + 現在値×5 | 3個 |

| 挑戦先 | 成功率 |
|---:|---:|
| +1～+3 | 100% |
| +4 | 85% |
| +5 | 70% |
| +6 | 55% |
| +7 | 42% |
| +8 | 32% |
| +9 | 24% |
| +10 | 18% |
| +11以降 | 1段階ごとに2%低下、最低5% |

基礎戦闘値は調律+1ごとに8%上昇する。通常工房の強化テーブルは参照しない。

### 異界の核

- FLOOR 25未満では出現しない。
- FLOOR 25～49: 核抽選2%
- FLOOR 50～99: 核抽選5%
- FLOOR 100～149: 核抽選8%
- FLOOR 150以降: 核抽選12%
- 金宝箱、深層レア敵、特殊カードでは別枠の確定・高確率報酬を設定できる。

## 6. OP移植

OP移植は採用する。ただし当たり個体を簡単に完成させないよう、次の制限を付ける。

- 移植元装備は消滅する。
- 1回の移植で選べるOPは1個だけ。
- 移植先に空き枠がなければ、既存OPを1個選んで上書きする。
- OPランクはそのまま引き継ぐ。
- 移植先の星で許される最大ランクを超える分は上限まで低下する。
- 《固有奏技》はOP移植の候補へ表示しない。
- 武器から武器、防具から防具だけ移植可能。部位や同名は問わない。
- 移植自体は失敗しない。
- 異界の欠片と異界の核を消費する。
- 変更前後、消滅する装備、移植OPを確認画面に並べ、確定まで素材を消費しない。

OPの自由な再抽選とOP枠追加は採用しない。良い個体と良いOP素材の両方を拾う意味を残す。

## 7. 保存構造

```text
profile.otherWorldGear[]
  uid              個体識別子
  itemId           異世界シリーズ専用装備ID
  stars            3～6
  quality          基礎個体値87～120
  tuneLevel        上限なし
  ops[]            OPキー・ランク・値
  locked           誤売却防止
  obtainedFloor    入手階
```

通常装備は従来どおり `profile.inventory` と `profile.equipment` を使用する。異世界装備は専用装備庫と専用装備スロット参照を使用し、通常工房の製作・強化・分解候補へ出さない。

## 8. 異世界共鳴セット

異世界シリーズはボス装備セットとは別枠の《異世界共鳴》として集計する。

- ボスシリーズの装備数には加算しない。
- ボスセットと異世界共鳴はそれぞれ独立して発動判定する。
- ボス装備と異世界装備を混ぜた場合、両方の条件を満たせば両方発動する。
- 同じ星の異世界シリーズだけを2・4・6部位で数える。
- ★3と★4など、異なるシリーズ同士の装備数は合算しない。
- 武器種が異なっても、同じ星のシリーズなら同一セットとして扱う。
- OPと個体値はセット判定に影響しない。

### セット効果

現行ボス装備の「能力+5%」「MP消費なし10%」「追加発動5%」より明確に強い、無限奏廊の上位報酬として設定する。

| シリーズ | 2 SET | 4 SET | 6 SET |
|---|---|---|---|
| ★3 境界 | 全基礎能力+5% | 与ダメージ+8%・被ダメージ-5% | 物理・魔法攻撃7%で追加発動 |
| ★4 深界 | 全基礎能力+8% | 与ダメージ+12%・被ダメージ-8% | 物理・魔法攻撃10%で追加発動・MP消費なし10% |
| ★5 幻奏 | 全基礎能力+12% | 与ダメージ+18%・被ダメージ-12% | 物理・魔法攻撃12%で追加発動・会心率+8% |
| ★6 無限 | 全基礎能力+16% | 与ダメージ+25%・被ダメージ-15% | 物理・魔法攻撃15%で追加発動・会心率+12%・戦闘中1回だけ致死ダメージをHP1で耐える |

全基礎能力は力、体力、魔力、精神、素早さ、器用さ、運を指す。最大HP・MPは含めない。

### UI

- 装備詳細に `OTHER WORLD RESONANCE 4 / 6` のように表示する。
- ボスセット欄とは別の枠・色で表示する。
- 発動中は明るく、未発動の次段階は暗く表示する。
- 異なる星を混ぜた場合は、シリーズごとの現在数を個別表示する。
- 装備変更確認では、変更によって消えるセット効果と新しく発動する効果を上下比較する。

## 9. 旧仕様から削除するもの

- 既存装備IDを使う無限ドロップ
- 既存装備へ付けるレアリティ別ランダム基礎倍率
- 同名・同レアリティ装備の合体
- 合体時のOP自動ランクアップ
- 帰還時に通常インベントリへ生成装備を加算する処理
- 通常工房のID共有強化値を異世界装備へ適用する処理

## 10. 実装順

1. ★3～★6の専用装備データと階層ドロップ表
2. 帰還後も個体を保つ《異世界装備庫》
3. 通常戦闘と無限奏廊の両方で個体装備を参照する集計処理
4. ボスセットと分離した《異世界共鳴》集計
5. 《異界の欠片》を使う調律画面
6. OP移植画面
7. 階層別の実測ドロップ試験と数値調整
