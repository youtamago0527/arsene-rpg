# D3 周回・クラフト設計 v0.2

## 基本ループ

D3は1回の直線踏破ではなく、隣接階を往復して素材・図鑑・武器学・JOBを育てる前提で設計する。

- 各階の通常出現種は5種。
- 2～3種は隣接階へ続投し、残りが次階の新種へ入れ替わる。
- 1～4Fは対策の理解、4F中ボス後の5～8FはD3クラフト装備を前提に能力が急上昇する。
- D2は低消耗で旧素材・特定武器学を育てる場所として残し、D3だけが常に最適解にはならない。

## 全階層レア遭遇

- メロクス：2.5%。〇〇クス族の先行個体。高EXP、超硬・高速。58%で逃走を選ぶ。逃げられた遭遇は階層勝利数へ加算しない。
- 黄金喰らい：3.5%。高GOLD。GOLDまたは所持素材を盗み、逃走する。撃破できれば盗品はすべて回収する。

## JOB別D3工房武器

戦士、魔導士、僧侶、武道家、魔奏士、双刃士、守護士にそれぞれ専用方向の武器を用意する。通常工房品はSTR/MAG等の基本値を直接上げず、攻撃・魔法攻撃・防御性能や固有割合効果を上げる。必要素材数は複数周回前提とする。

希少敵素材は最上位の魔奏士武器と守護士盾へ要求し、レア遭遇が周回の明確な当たりになるようにする。
