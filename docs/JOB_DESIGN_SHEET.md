# 或世盗 JOB設計シート

新しいJOBは、下の項目を埋めてから実装する。決まっていない項目は「未定」と書けばよい。
構想だけでも、役割・得意なこと・弱点の3点があれば残りは既存JOBとの比較から仮案を作れる。

## 最小入力（構想段階）

```text
JOB表示名：
一言コンセプト：
戦闘で一番得意なこと：
明確な弱点：
得意武器：
相性を持たせたい既存JOB：
解放する場所／ボス：
```

## 実装完了条件

- `jobs` にJOB定義がある
- `jobCommandAbilities` に戦闘コマンドがある
- 成長が `jobGrowthPerLevel` へ登録されている
- 固有技に `signatureSkillId` が接続されている
- パッシブが `passiveUnlocks` へ接続されている
- 通常JOB技が `skillUnlocks` へ接続されている
- 全参照先のスキルIDが存在する
- 解放前はJOB一覧に表示されない
- Lvアップ、MASTER、転生、セーブ復帰を確認する
- ファントムシーフへ成長とMASTER固有技が反映される
- 同名・同ID・同じ役割の既存JOBがないか監査する
- D3基準のDPS・被ダメ・GOLD効率を再計算する

ゲーム起動後、開発者コンソールで `ARSENE_JOB_AUDIT.report()` を実行すると、
現在の全JOBの不足・参照切れ・重複を表形式で確認できる。
新案は `ARSENE_JOB_AUDIT.auditCandidate({...})` に渡すと既存JOBとの衝突を確認できる。
