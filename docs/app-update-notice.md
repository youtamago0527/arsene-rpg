# アップデートのお知らせ

iOSアプリの拠点「お知らせ」から開く。ログインボーナス入りのビルドでは、同じ画面に「アップデート情報」が追加され、報酬の操作も引き続き使える。バッジは告知を開くと消える。更新済みの場合は変更点だけが表示される。

## 配信の準備

- 公式サイト `arsene-rpg.pages.dev` の `/game/data/app-update-notice.json` に、最初は `{"enabled": false}` を配置する。サイトのデプロイでは既存ページ・アセットを含めて維持する。
- URLがHTTP 200でJSONを返し、Capacitorの `Origin: https://localhost` のリクエストを許可することを確認する。配信サーバーに接続できない場合は、アプリに同梱した `data/app-update-notice.json` の変更点を表示する。
- 承認に加え、対象バージョンがApp Storeで実際に公開されたことを確認してから `enabled` を `true` にする。告知を差し替えるときは未読用の `id` を変える。告知停止は `enabled: false` で行える。

例（バージョンと変更内容は実際に公開した版に合わせる）。

```json
{
  "enabled": true,
  "id": "release-1.0.6",
  "version": "1.0.6",
  "title": "アップデートを配信しました",
  "changes": ["拠点の「お知らせ」からアップデート情報を確認できます。"]
}
```

## 審査用ビルドにまとめる前の確認

- 装備・OPの確定差分を同じ検証ビルドに取り込み、ログインボーナスの受け取り、既存セーブからの装備表示、OP表示を確認する。
- 配信前の確認はテスト用の告知を使い、iPhoneで旧版からのApp Store遷移、最新版の変更点表示、通信できない場合の拠点操作を確認する。
- App Storeの「このバージョンの最新情報」には実際に入った装備・OP更新の項目を追加する。審査の提出は別途。
