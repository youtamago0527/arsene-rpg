## 2. ゲームの基本ループ

1. 6人から主人公を選び、表示名を決める。
2. 初期武器を剣・体術・杖から選ぶ。
3. 拠点でJOB、装備、所持品、料理、図鑑を整える。
4. D1〜D3へ潜入し、敵を倒して素材・GOLD・経験値・JOB経験値・武器学経験値を得る。
5. 工房で装備を作成・強化する。
6. ボスを倒してSCORE、JOBの証、武器カテゴリ、工房レシピを解放する。
7. JOB Lv20到達後は、転生により一部能力を残して再育成する。
8. 異世界では自動的にPHANTOM THIEFとなり、曜日アルカナを集める。

敗北または拠点帰還で潜入は終了し、料理の潜入バフは消滅する。

## 6. 戦闘

### 6.1 ターンとコマンド

- 基本はプレイヤーACTION後に敵ACTION。
- メインコマンド: たたかう / 武器技 / スキル / 防御 / アイテム / リピート / 一掃 / AUTO
- 防御はそのラウンドに受ける最終ダメージを50%軽減する。
- リピートは直前の有効な行動を再実行する。
- AUTOは `OFF → ×1.5 → ×2 → OFF` の順で切り替わり、次の通常戦闘へ継続する。
- 簡易戦闘は通常演出を短縮して連戦を進める。
- 敵本体タップで対象を決定でき、敵名プレートから状態詳細を確認できる。

### 6.2 会心

```text
基本会心率 = 6% + LUK ×0.8%
通常上限 = 28%
会心ダメージ = 1.65倍
```

装備、技、PASSIVE、キャラクター適性、双刃士の連舞などの補正は別途加算される。

### 6.3 敵から受けるダメージ

```text
物理基礎 = 敵ATK ×0.70 × 40 / (40 + 物理防御)
魔法基礎 = 敵MAG ×0.78 × 40 / (40 + 魔法防御)
敵側乱数 = -1 ～ +2
```

- 物理防御はVITと装備DEFを参照する。
- 魔法防御はMNDと装備MDEFを参照する。
- 最低ダメージは1。
- 命中、回避、必中、貫通、BUFF/DEBUFFを行動ごとに処理する。

### 6.4 武器の主参照

| 武器 | 主参照 |
|---|---|
| 剣 | 武器ATK + STR |
| 体術 | 武器ATK + STR×0.5 + AGI×0.5 |
| 杖 | 武器MAG + MAG |
| 楽器 | DEXを主軸とする演奏・複合攻撃 |
| 盾 | 盾DEF×0.5 + 盾MDEF×0.5 |

装備種別ごとの技倍率、Hit数、追加効果はデータ定義を参照する。

## 7. 成長、武器学、Spark

### 7.1 基礎成長

- 戦闘中の行動や被弾を通じ、HP/MPが確率成長する。
- HP基本成長率15%、MP基本成長率8%。
- HP成長量1〜5、MP成長量1〜3。
- JOBとキャラクター適性で確率が補正される。

### 7.2 武器学

- 武器を使ったACTIONで武器学経験値を得る。
- 基本ACTIONは1、強いACTIONは2。
- 1Lvごとに最終ダメージ+0.5%。
- 原則として1戦闘中の武器学レベルアップは1回まで。

### 7.3 Spark

- 敵のSpark Lvと自分の武器学Lvの差から基本確率を求める。
- 基本率は差により15% / 12% / 8% / 5% / 2% / 1% / 0.5% / 0%。
- 通常攻撃由来×0.25、関連技由来×0.5、直接派生×2.0。
- 初回Sparkで発動した技はMP0。
- 習得した技は武器学とともに保存される。

## 8. JOB共通仕様

- 通常JOBは自JOBで習得済みのPASSIVEが自動で有効。
- さらに、他JOBで習得済みのPASSIVEを1枠装備できる。
- 通常JOBは他JOBのACTION技を装備できない。
- PHANTOM THIEFはACTION 2枠、PASSIVE 2枠をRE:MIXできる。
- 習得したACTION/PASSIVEは転生後も失わない。
- JOB Lv20がMASTER基準。

### 8.1 現行JOB

| JOB | 固有ACTION | PASSIVE習得 | 主な役割 |
|---|---|---|---|
| 戦士 | ちからため | 練達 / 怪力 / 頑強 / 闘争本能 | STR・VIT、反撃、正面耐久 |
| 魔導士 | 精神集中 | 魔力増幅 / 魔力貯蔵 / 魔法増幅 | MAG・MND、魔法火力、MP循環 |
| 武道家 | ばくれつけん | 疾風 / 急所狙い / 幸運 | AGI・LUK、多段、会心 |
| 僧侶 | ヒール | 施しの祈り / 祈祷 / 治癒術 / 魔法障壁 | 回復、継戦、GOLD周回、確率即死 |
| 魔奏士 | アンサンブル | ソロ / フォルテ / クレッシェンド / ノクターン | 楽器、確率BUFF、物魔複合 |
| 魔奏聖 | ― | ― | 魔導士Lv20・僧侶Lv20の上位複合JOB |
| 双刃士 | 戦姫乱舞 | 二刀の型 / 連舞 / 追刃 / 舞踏の型 | STR・AGI、二刀追撃、会心加速 |
| 守護士 | 共鳴破 | 現行は専用共鳴システム中心 | 盾、防御、反撃、格上耐久 |
| PHANTOM THIEF | RE:MIX | 他JOBから2枠 | 異世界専用、成長合算、ロマン構築 |

### 8.2 僧侶の資源循環

- 《リジェネ》: MP8、3ターン、各ターン35%で最大HP15%回復。
- 《ボディトゥマインド》: 1戦1回、最大HP20%消費、最大MP25%回復。
- 《祈祷》: 最大HP10%以上の敵被ダメ時、1ラウンド1回40%抽選。成功時3ターンの再生。自傷では発動しない。
- 《魂送の祈り》: MAG+MNDと敵MNDから即死率を算出。通常敵のみ有効で、ボス・撃破不能・無限HPには無効。
- 能動リジェネとHP→MP変換は平均上ほぼ等価だが、HP→MPは1戦1回のため永久機関にはならない。抽選が上振れした場合のみHP/MP両満タンが起こり得る。

### 8.3 守護士の共鳴

- 実被ダメージの5%をRESONANCEとして蓄積。最大100。
- 共鳴破倍率: 1以上×1.0、25以上×1.25、50以上×1.5、75以上×1.75、100×2.0。
- フォートレスは被ダメージ30%軽減。
- 盾攻撃は盾DEFと盾MDEFを各50%参照する。

### 8.4 双刃士の連舞

- 攻撃命中で連舞を蓄積し、最大5。
- 1段階ごとに最終ダメージ+2%、最大時は会心+10%、AGI+20%、左手追撃率+10%。
- 左手追撃は基礎25%で、転生によって段階強化される。
- 高会心・高手数の代わりに、防御・魔防・自己回復が低い。

### 8.5 魔奏士と《ノクターン》

現行値:

- フォルテ／クレッシェンドの基本発動率は50%。
- 《ノクターン》だけは耐久JOBとの組み合わせを考慮し、基本発動率30%。
- 《アンサンブル》中の《ノクターン》は同じ1.5倍補正で45%。
- 《ノクターン》は発動すると3ターン、ターン開始時に最大HP8%を回復する。
- 効果中の再発動で残りターンを更新できる。
- 楽器装備条件がなく、他JOBのPASSIVE枠でも発動する。

単純な独立抽選で「直近3ターンに1回以上発動している確率」を稼働率の目安にすると:

```text
通常: 1 - (1 - 0.30)^3 = 65.7%
アンサンブル中: 1 - (1 - 0.45)^3 = 83.3625%
```

戦士や守護士に装備すると耐久型ビルドが成立する。特に守護士は長期戦の累積与ダメージも伸びるが、50%時のほぼ常時再生は避け、30%で「気づくと強い」隠れた組み合わせとして残す。

## 9. 転生

- 解放: ミルティ撃破。
- 条件: 対象JOB Lv20、輪廻のアルカナ1個。
- 転生後: JOB Lv1、JOB EXP0。
- Lvアップで得た能力の20%を基礎側へ残す。
- 次の育成で得るJOB成長は転生1回ごとに+10%。
- 習得済みACTION/PASSIVEは維持する。
- PASSIVE習得Lvへ再到達すると、対応するPASSIVEが1段階強化される。
- 通常の段階強化量は元効果の40%。個別テーブルや上限がある場合はそちらを優先する。
- PHANTOM THIEF自身は転生・Lv成長を行わない。

### PHANTOM THIEFへの成長反映

- 通常キャラクター: 各通常JOBで得た成長の50%を合算。
- 京介: 60%を合算。
- 曜日アルカナによる基礎能力上昇: 全キャラクター100%。
- 異世界へ入ると自動でPHANTOM THIEFへ変更し、帰還すると直前の通常JOBへ戻る。

## 13. 異世界・曜日ダンジョン

《無限奏廊》ではなく、通常の異世界曜日ダンジョンだけを本書の対象とする。

- 異世界進入時はPHANTOM THIEFへ自動変更。
- 帰還時は直前の通常JOBへ復帰。
- 通常のEXP、GOLD、JOB EXP、武器学経験値は得ない。
- 1回10戦、9戦目まで通常敵、10戦目がボス。
- 曜日ごとの能力アルカナを獲得する。

| 難易度 | 敵 | 報酬 |
|---|---|---|
| 初級 | D1系 | 通常敵アルカナ1%抽選、ボス1個確定 |
| 中級 | D2色違い、初級能力の正確な2倍 | 通常・宝箱報酬数2倍、ボス2個確定 |

曜日:

- 日: ランダム
- 月: STR
- 火: VIT
- 水: MAG
- 木: MND
- 金: AGI
- 土: LUK

能力アルカナは`baseStats`へ直接+1される恒久成長で、JOB変更後も残り、PHANTOM THIEFでも100%反映される。

## 14. DEBUGと現行ランキング

JOB LABの現行主要カテゴリ:

- 雑魚殲滅速度
- 周回速度
- 単体DPS
- 複数DPS
- 被ダメージ
- 回避
- 会心
- 一撃最大値
- GOLD効率
- 強敵生存ACTION

PHANTOM THIEFは通常ダンジョン用JOBではないため、通常JOBの平均順位調整から除外する。

### 14.1 現行ランキングの重要な限界

現在の計算は、各JOB自身の習得PASSIVEと代表装備・代表行動を主に比較する。通常JOBが装備できる「他JOB PASSIVE 1枠」の全組み合わせは総当たりしていない。

したがって、以下は未評価:

- 戦士 + ノクターン
- 守護士 + ノクターン
- 双刃士 + ノクターン
- その他すべてのJOB × 他JOB PASSIVE

また、表示上のDPSは場面によって「1ACTION平均ダメージ」に近い。実戦のMP枯渇、CT、回復、行動ローテーションを完全再現した秒間DPSではない。

## 15. リリース前JOBバランスの必須検証

数値変更は本書作成時点では行わない。次の調整フェーズで、無限奏廊・D4〜D7予約JOBを除外し、現在解放可能な通常JOBだけを対象に再計算する。

### 15.1 必須ケース

1. 各JOB純正構成。
2. 各JOB × 全ての装備可能な他JOB PASSIVE。
3. 戦士 + ノクターン。
4. 守護士 + ノクターン。
5. 双刃士 + ノクターン。
6. 魔奏士自身の通常時 / アンサンブル時。
7. D1〜D3雑魚、複数敵、通常ボス、格上強敵。
8. 30ACTION / 100ACTIONの継戦。
9. MP枯渇、回復量、反撃回数、会心率、被ダメージを含む実ローテーション。

### 15.2 合格の考え方

- 戦士は全ランキングの中央付近を基準にする。
- 双刃士は会心・手数・短期単体火力で優位、耐久では不利。
- 守護士は格上相手の生存・反撃・被ダメージで1位候補。
- 僧侶は回復・長期潜入・GOLD効率で価値を持つ。
- 魔奏士は確率BUFFと楽器専用技の構築価値を持つ。
- 後半JOBが平均でわずかに強いのは許容する。
- どのJOBも複数カテゴリの平均順位が極端に沈まないようにする。
- 1位の数を揃えることより、明確な長所と実戦で選ぶ理由を優先する。

### 15.3 《ノクターン》の決定

通常50%では守護士への耐久寄与が過剰だったため、《ノクターン》だけ30%へ分離した。フォルテ／クレッシェンドの50%は維持する。今後さらに過剰な場合のみ、次のいずれかを検討する。

- 発動率を下げる。
- 発動中は再抽選しない。
- 再発動で残りターンを更新しない。
- 内部クールダウンを設ける。
- 楽器装備中のみ有効にする。
- 他JOB装備時だけ回復率を下げる。
- MND参照へ変更し、戦士・守護士の無条件高回復を抑える。

30%時点では、僧侶の回復特化、守護士の再生防御、戦士の反撃耐久という別の遊び方を残す。

## 18. このチェックポイントでの結論

- 通常ゲームは、D1〜D3、転生、装備、曜日異世界までを一つのリリース候補範囲として整理できる。
- 双刃士の会心型と戦士・守護士の耐久型は、方向性として差別化できている。
- 《ノクターン》は専用発動率30%・3ターン更新へ調整し、他JOB持ち込み時の稼働率目安を65.7%まで抑えた。
- よって、次の最終調整は「JOB単体」ではなく「JOB × 他JOB PASSIVE 1枠」のビルド単位で行う。
- 無限奏廊はこの調整を確定した後、別バランスとして制作・検証する。
